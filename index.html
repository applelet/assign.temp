PROBLEM STATEMENT
Write a program to calculate the average of three numbers.
ALGORITHM
Algorithm: average_of_three_numbers Input: a, b, c Output: Average of three numbers. Step 1 [Read]: Read a, b, c Step 2 [Assign]: sum ← a + b + c avg ← sum / 3 Step 3 [Output]: print avg Step 4: Exit
SOURCE
C Source Code Edit Mode → click code to edit
#include <stdio.h> int main() { float a, b, c, sum, avg; printf("Enter First Number: "); scanf("%f", &a); printf("Enter Second Number: "); scanf("%f", &b); printf("Enter Third Number: "); scanf("%f", &c); sum = a + b + c; avg = sum / 3; printf("Average: %.2f\n", avg); return 0; }
INPUT / OUTPUT
Input Output
Enter First Number: 10.5 Enter Second Number: 20.0 Enter Third Number: 30.25 Average: 20.25
DISCUSSION

This program reads three decimal numbers from the user, adds them together, and divides the sum by three. It uses float types for precision and formats the final average to two decimal places.

The program ran successfully, correctly calculating and printing the average of 20.25 for the inputs 10.5, 20.0, and 30.25.
